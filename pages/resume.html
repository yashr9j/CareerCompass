Resume Guide & Skills Checklist

Your resume is your first impression — and for most tech companies, it is the only thing that decides if you get an interview or not. This page covers exactly what to include, how to format it, what recruiters look for in 6 seconds, and a complete skills checklist to identify your gaps.

Ideal Resume Structure for Freshers

Section Order (Most to Least Important for Freshers)

  1. Header — Name, phone, email, LinkedIn URL, GitHub URL, portfolio link
  2. Education — Institution, degree, branch, CGPA, year of graduation
  3. Technical Skills — Languages, frameworks, tools, databases (grouped by category)
  4. Projects — 2–4 projects with tech stack, impact metrics, GitHub link
  5. Experience — Internships, research positions, part-time roles (if any)
  6. Achievements — Competitive programming ratings, hackathon wins, certifications
  7. Extracurriculars — Leadership roles, clubs, open source contributions (keep brief)

Golden Rules of Fresher Resumes

  • Keep it strictly to ONE page — no exceptions for freshers
  • Use a clean, ATS-friendly format — no tables, columns, or graphics in the PDF
  • Quantify everything: "Reduced API response time by 40%" beats "Improved performance"
  • Use action verbs to begin each bullet: Built, Designed, Implemented, Optimized, Deployed
  • Tailor the skills section to match keywords in the job description
  • Export as PDF — never submit as .docx unless specifically asked
  • Name the file: FirstName_LastName_Resume.pdf — not "resume_final_v3.pdf"

What Recruiters See in 6 Seconds

Recruiter Eye-Tracking Study — Elements Scanned First (LinkedIn, 2023)
Priority Element What They Check Common Mistakes
1st Name & Contact Professional email, LinkedIn URL Using personal/funny email IDs
2nd Education College, degree, CGPA, graduation year Missing graduation year or CGPA
3rd Skills Language/framework match with JD keywords Listing irrelevant or outdated tools
4th Projects / Experience Impact, tech stack, GitHub link Vague descriptions with no metrics
5th Achievements LeetCode rating, hackathon wins, certs Listing irrelevant school achievements

Valuable Free Certifications

  1. Google Data Analytics Certificate (Coursera) — Audit free; recognized by employers; covers SQL, R, Tableau basics
  2. AWS Cloud Practitioner (Free Training) — AWS Skill Builder offers free training; exam costs ~$100 but widely recognized
  3. DeepLearning.AI — Machine Learning Specialization — Andrew Ng's flagship course; audit free on Coursera
  4. Meta Front-End Developer Certificate (Coursera) — HTML, CSS, React, version control; audit free
  5. Microsoft Azure Fundamentals (AZ-900) — Free learning path on Microsoft Learn; exam vouchers sometimes available for students
  6. Kaggle Micro-Courses — Python, SQL, ML, Deep Learning, Feature Engineering — all free with certificates
  7. NPTEL Courses (IIT Faculty) — Free with paid exam option; widely respected by Indian employers; many CS/ML courses available

Bad vs Good Project Description Examples

How to Write Project Bullets That Get Noticed
Bad (Vague) Good (Specific + Impact)
"Made a website using HTML and CSS" "Built a 4-page responsive mental wellness portal in HTML5 with semantic markup, 5 data tables, and a multi-input contact form"
"Trained a machine learning model" "Trained a Random Forest classifier on 50K patient records achieving 91% accuracy for disease prediction; deployed via Flask API"
"Created a Python project" "Built a CLI-based Student Records Management System in Python handling CRUD operations for 500+ entries with file persistence"
"Worked on a team project" "Led 3-member team to build an e-commerce scraper using BeautifulSoup and SQLite; reduced data collection time from 4 hours to 12 minutes"
