## Project Title
**CareerCompass — Student Career Guidance & Roadmap Portal**

## Project Description
CareerCompass is a frontend-only, HTML5 career guidance web portal built specifically for engineering undergraduates. It provides structured career roadmaps for SDE, ML Engineer, and Data Analyst tracks, a comprehensive internship hunting guide with platform and company listings, a resume writing guide with do's and don'ts, a skills checklist by role and proficiency level, and a full career counseling request form.

Built with pure HTML5 (no CSS or JavaScript), the site demonstrates professional use of semantic elements, data tables, forms, ordered/unordered lists, figures, and consistent navigation.

## Problem Statement
Engineering students in India often graduate without clear career direction, missing internship windows, building the wrong skills, or writing weak resumes — simply due to lack of accessible, structured guidance. CareerCompass addresses this by centralizing career roadmaps, internship strategies, and resume best practices in one easy-to-navigate HTML portal.

## Objectives
1. Provide structured, phase-wise career roadmaps for the top 3 tech career tracks
2. Guide students on when and where to apply for internships with a curated platform list
3. Teach resume writing best practices with concrete good vs bad examples
4. Offer a skills self-assessment checklist to help students identify knowledge gaps
5. Build a complete HTML5 multi-page website meeting all assignment criteria
6. Practice team collaboration using Git and GitHub with traceable contributions

## Target Users
- B.Tech 1st–4th year students in CSE, AI-ML, IT, and related branches
- Students preparing for campus or off-campus placements
- Students seeking internship guidance and resume help
- Faculty advisors looking for structured student career resources
